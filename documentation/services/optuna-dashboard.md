# Optuna Dashboard

A real-time web dashboard for Optuna, used to visualize and analyze hyperparameter optimization studies.

**[Website](https://optuna.org/)** | **[Documentation](https://optuna.readthedocs.io/projects/optuna-dashboard/)** | **[GitHub](https://github.com/optuna/optuna-dashboard)**

## How to enable?

```
platys init --enable-services OPTUNA_DASHBOARD
platys gen
```

## How to use it?

Navigate to <http://dataplatform:28231>
