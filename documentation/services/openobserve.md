# OpenObserve

Cloud-native observability platform for logs, metrics, traces, analytics, and dashboards. OpenObserve provides a unified solution for ingesting and querying telemetry data with a built-in UI, SQL-based query interface, and high compression storage.

**[Website](https://openobserve.ai/)** | **[Documentation](https://openobserve.ai/docs/)** | **[GitHub](https://github.com/openobserve/openobserve)**

### How to enable?

```
platys init --enable-services OPENOBSERVE
platys gen
```

### How to use it?

Navigate to <http://dataplatform:5080>

Login with the email configured in `OPENOBSERVE_root_user_email` (default: `root@example.com`) and the password configured in `OPENOBSERVE_root_user_password` (default: `abc123!`).
