# Jikkou API Server

Jikkou API Server exposes the Resource as Code capabilities of Jikkou for Apache Kafka over a REST API.

**[Website](https://streamthoughts.github.io/jikkou/)** | **[Documentation](https://streamthoughts.github.io/jikkou/docs/)**
| **[GitHub](https://github.com/streamthoughts/jikkou)**

## How to enable?

```bash
platys init --enable-services JIKKOU_SERVER
platys gen
```

## How to use it?

The REST API is exposed on <http://dataplatform:28388>.
