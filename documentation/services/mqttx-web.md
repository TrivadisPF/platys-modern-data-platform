# MQTTX Web

A Powerful and All-in-One MQTT 5.0 client toolbox for Desktop, CLI and WebSocket. This container runs the MQTTX web client.

**[Website](https://mqttx.app/)** | **[Documentation](https://mqttx.app/docs)** | **[GitHub](https://github.com/emqx/MQTTX)**

## How to enable?

```
platys init --enable-services MQTTX_WEB
platys gen
```

## How to use it?

Navigate to <http://dataplatform:28367>.
