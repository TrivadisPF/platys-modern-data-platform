# Opik

Opik is an open-source LLM engineering platform for evaluating, testing, and monitoring LLM applications.

**[Website](https://www.comet.com/site/products/opik/)** | **[Documentation](https://www.comet.com/docs/opik/)**
| **[GitHub](https://github.com/comet-ml/opik)**

## How to enable?

```bash
platys init --enable-services OPIK
platys gen
```

## How to use it?

Navigate to <http://dataplatform:5173>
