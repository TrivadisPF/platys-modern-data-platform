# Dockhand

Dockhand is a lightweight Docker container management UI that lets you view, start, stop, and manage containers directly from your browser.

**[GitHub](https://github.com/fnsys/dockhand)**

## How to enable?

```
platys init --enable-services DOCKHAND
platys gen
```

## How to use it?

Navigate to <http://dataplatform:28498>.
