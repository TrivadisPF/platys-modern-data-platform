# pREST

pREST (PostgreSQL REST) is a fully RESTful API from any existing PostgreSQL database, written in Go. It provides a simple and secure way to expose your PostgreSQL data over HTTP without writing any code.

**[Website](https://prestd.com/)** | **[Documentation](https://docs.prest.com.br/)** | **[GitHub](https://github.com/prest/prest)**

## How to enable?

```
platys init --enable-services PREST
platys gen
```

## How to use it?

Navigate to <http://dataplatform:28215>
